## ✨ Tutorial Highlights

- **🌱 The first systematically open-sourced AI Agent tutorial on the internet**: This is a long-term maintained AI large language model application development roadmap. The market doesn't lack scattered posts or paid bootcamps, but truly systematic, continuously updated AI large language model application tutorials covering **tutorials + source code + hands-on projects + interview question bank** are extremely rare. What this repository aims to do is make this path public, deep, and complete, growing with you from beginner to advanced to hands-on project practice.
- **🧭 One thread connecting the full stack of large language model applications**: From large language models and prompts, to low-code (Coze/Dify) and code frameworks (LangChain/LangGraph), then to enterprise-level RAG/Agent, fine-tuning, and engineering standards — all organized uniformly by knowledge system, forming a **complete chain** closed loop, suitable for systematic mastery rather than fragmented bookmarking.
- **🐍 Focused on the Python ecosystem, directly targeting Agent engineering**: Many courses revolve around **Spring AI** and **langchain4j**, leaning more toward the Java tech stack. This tutorial's main line focuses on **Python + LangChain + LangGraph**, directly aligning with the most commonly used engineering path for current AI Agent / large language model application development.
- **📘 Accessible for beginners, deep enough for engineers**: The entire tutorial is organized in a **progressive** manner, first thoroughly explaining core concepts like large language models, Agent, RAG, MCP, and Tool Calling, then diving into source code, frameworks, deployment, and project design. Less mystical jargon, more "why it's designed this way, how the code runs, how the project gets deployed."
- **💼 Enterprise-level hands-on, benchmarked against "can actually get the job done"**: Centered on Shopkeeper Data Q&A, Deep Research, Shopkeeper Knowledge Base, and E-commerce Assistant as the main threads, connecting intent parsing, multi-source knowledge, human handoff, retrospective analysis, and monitoring; practicing **multi-route retrieval, evaluation, observability, cost, guardrails** in real contexts. You'll have concrete talking points for your resume and project presentations — not vague.
- **✅ Every case is held to the standard of "can actually run"**: Not just explaining concepts or pasting pseudocode, but providing **runnable cases, source code, environment setup instructions, and common troubleshooting** wherever possible. All case content is organized based on the approach of actually running through things manually, helping you avoid pitfalls and get started quickly.
- **📚 Tutorial, source code, and interviews — a trinity that actually works**: Not just "finish reading," but "run it through" and "answer it out loud" — **runnable cases and source code**, **prompt templates** and deployment approaches, rejecting "concepts only." The interview question bank organizes questions by common competency domains from **training programs and JDs**, with a significant portion compiled from **real interview questions from major tech companies**, public interview experiences, and high-frequency follow-up scenarios, suitable for career changers/fresh graduates doing focused review.
- **🚀 Facing 2026, continuously evolving and hardcore**: The tech stack and high-frequency question patterns will iterate with the ecosystem, aligned with the 10,000-yuan-level training curriculum dimensions for "AI Application Development Engineer"; not just telling you "what to learn," but also "how to do projects, how to present projects, how to answer interviews." ## 🚀 Quick Start

Study together with the [Online Documentation](https://didilili.github.io/ai-agents-from-zero/#/). Want to run a case right away? Just follow the steps below. For more detailed environment instructions, API applications, and common error handling, see [Beginner's Guide and FAQ](../../%E6%96%B0%E6%89%8B%E5%85%A5%E9%97%A8%E4%B8%8E%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98.md).

1. **Clone the repository and enter the project directory**

   ```bash
   git clone https://github.com/didilili/ai-agents-from-zero.git
   cd ai-agents-from-zero
   ```

2. **Prepare the environment** (Python 3.10 recommended, supports 3.10–3.13)

   ```bash
   python3.10 -m venv .venv
   source .venv/bin/activate          # macOS/Linux
   # .venv\Scripts\activate           # Windows CMD
   pip install -r requirements.txt
   ```

3. **Configure API Key**
   - Copy `.env-example` in the root directory to `.env`; on the web page you can directly view the [configuration example](../../%E6%96%B0%E6%89%8B%E5%85%A5%E9%97%A8%E4%B8%8E%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98.md#_4、配置-api-key-与-env)
   - Fill in your API Key in `.env` (such as Qwen/Alibaba Bailian, DeepSeek, etc.), and variable names must match the code (such as `aliQwen-api`, `QWEN_API_KEY`, `deepseek-api`)
   - For how to apply for keys on each platform, see [Beginner's Guide and FAQ - How to Apply for Keys on Each API Platform](../../%E6%96%B0%E6%89%8B%E5%85%A5%E9%97%A8%E4%B8%8E%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98.md#_5、各-api-平台如何申请-key？)

4. **Run the first case in the project root directory**

   ```bash
   python 案例与源码-2-LangChain框架/01-helloworld/StandardDesc.py
   ```

   **Recommendation**: Execute `python` in the **project root directory** to facilitate unified management of the virtual environment, dependencies, and output files. In ordinary scripts, `load_dotenv()` usually automatically searches upward for `.env`; if you use an IDE, REPL, or debugger and cannot read the Key, please check its working directory configuration. If you do not want to use a cloud API, you can use [Ollama local models](../../%E6%96%B0%E6%89%8B%E5%85%A5%E9%97%A8%E4%B8%8E%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98.md#_54-不想用云-api：用本地-ollama（无需-key）) (no Key required).

If you encounter `ModuleNotFoundError`, API Key errors, cannot find `.env`, etc., please see [Beginner's Guide and FAQ - Common Problems and Solutions](../../%E6%96%B0%E6%89%8B%E5%85%A5%E9%97%A8%E4%B8%8E%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98.md#_6、常见问题与解决).
