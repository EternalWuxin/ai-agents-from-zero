**Tutorials and Documentation**

This update rewrites Chapter 28 and adds Chapters 29-33, using "Chinese keyword extraction" as the running case study to connect data preparation, training, evaluation, and model delivery into a complete learning path:

- [Chapter 28 "Overview and Overall Workflow of LLM Fine-tuning"](28-%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%BE%AE%E8%B0%83%E6%A6%82%E8%BF%B0%E4%B8%8E%E6%95%B4%E4%BD%93%E6%B5%81%E7%A8%8B.md): Starting from specific problems, determine when fine-tuning is needed, and understand model selection, task conventions, and baseline comparison.
- [Chapter 29 "Fine-tuning Data Preparation and Chat Templates"](29-%E5%BE%AE%E8%B0%83%E6%95%B0%E6%8D%AE%E5%87%86%E5%A4%87%E4%B8%8E%E5%AF%B9%E8%AF%9D%E6%A8%A1%E6%9D%BF.md): Clearly explains JSONL, Alpaca / ShareGPT, sample review, cleaning and deduplication, data splitting, and chat templates, with a document Q&A data creation exercise.
- [Chapter 30 "Model Training Principles and Efficient Fine-tuning"](30-%E6%A8%A1%E5%9E%8B%E8%AE%AD%E7%BB%83%E5%8E%9F%E7%90%86%E4%B8%8E%E9%AB%98%E6%95%88%E5%BE%AE%E8%B0%83.md): Use concrete examples to understand Loss, gradients, batches, learning rate, memory, and numerical precision, then learn LoRA / QLoRA, training logs, and checkpoints.
- [Chapter 31 "LLaMA-Factory Environment Setup and Fine-tuning Practice"](31-LLaMA-Factory%E7%8E%AF%E5%A2%83%E6%90%AD%E5%BB%BA%E4%B8%8E%E5%BE%AE%E8%B0%83%E5%AE%9E%E6%88%98.md): Follow the AutoDL single-GPU case to complete environment preparation, data registration, parameter configuration, training launch, log inspection, and result backup.
- [Chapter 32 "Fine-tuning Effect Evaluation and Model Deployment"](32-%E5%BE%AE%E8%B0%83%E6%95%88%E6%9E%9C%E8%AF%84%E4%BC%B0%E4%B8%8E%E6%A8%A1%E5%9E%8B%E9%83%A8%E7%BD%B2.md): Compare the answers of the original model and the fine-tuned model, complete batch prediction, keyword scoring, error analysis, and regression checks, learn model merging and export, and provide optional content on vLLM deployment and API invocation.
- [Chapter 33 "Fine-tuning Memory Optimization and Multi-GPU Training"](33-%E5%BE%AE%E8%B0%83%E6%98%BE%E5%AD%98%E4%BC%98%E5%8C%96%E4%B8%8E%E5%A4%9A%E5%8D%A1%E8%AE%AD%E7%BB%83.md): Learn how to troubleshoot insufficient memory, compare memory and time consumption across different configurations, understand three parallelism approaches, DeepSpeed ZeRO, and the trade-offs when trial-running large models.
